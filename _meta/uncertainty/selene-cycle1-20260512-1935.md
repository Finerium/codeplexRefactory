## U2 (low): Recharts SSR hydration warnings

**Concern**: Recharts uses ResizeObserver internally. Next.js 16 server-renders without DOM dimensions, client paints after measurement. Potential hydration mismatch warning.

**Mitigation**:
- Mark every chart component `'use client'`
- Wrap charts in `<Suspense fallback={<ChartSkeleton />}>` OR pin `recharts@^2.13` which handles initial-dimension defaults.
- Skip suspense for now (medium complexity Cycle 2), validate at Cycle 3 smoke test. If warnings appear, fix with `<Suspense>`.

**Risk if NOT mitigated**: console warnings (cosmetic). Lighthouse audit may flag CLS (Cumulative Layout Shift) if dimensions render late.
