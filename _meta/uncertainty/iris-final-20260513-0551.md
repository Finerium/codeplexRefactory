## Medium-confidence concerns

### C-Final-1: STREET_GAP 3.6 may shrink small leaf rectangles to MIN_FOOTPRINT clamp

The squarified treemap allocates rectangles proportional to weight. Small files
(low weight) get small rectangles. With STREET_GAP 3.6, a 4x4 rectangle inset
becomes (4 - 3.6) = 0.4 width which clamps to MIN_FOOTPRINT 2.4. This means
many small files now share the SAME footprint width 2.4 + same depth 2.4 +
their height differs (height encodes LOC independently). Visual effect:
small files cluster together as a "row of identical footprints with varying
heights". This is acceptable as a visual identifier of "small files folder"
but may read as repetitive at zoom-in. Mitigation deferred to Hera Wave 2
overlay tier if Ghaisan flags.

### C-Final-2: Camera zoom range bumped maxDistance 220 to 320

If user zooms out to 320 unit, the city extent 320x320 fully visible but the
DOF focusDistance 0.045 (~27 unit) puts the entire scene out of focus. The
existing 900ms DOF-defer (Daedalus D fix) only protects first frame. Manual
zoom to far distance during pitch demo would re-introduce DOF blur. Mitigation:
director-mode auto-fly stays within 50-180 unit envelope per WF#2 D13 ship
so panitia demo path is safe. Manual exploration is at-user-risk; documented.

### C-Final-3: Window shader uniforms global registry not garbage-collected on unmount

The `registerWindowMaterial` returns an unregister function but
`tickWindowMaterials` iterates the module-scope REGISTRY without lifecycle
awareness. If a future Wave 3 worker mounts/unmounts BuildingInstances
multiple times (e.g., tab switch), the REGISTRY would grow. For Wave 1 ship
+ pitch demo this is irrelevant (single mount). Mitigation: add per-material
useEffect cleanup that calls the unregister return value, deferred since
materials are built once at module load and never disposed in current
architecture.

### C-Final-4: 320x320 canvas + 0.4x district tree scatter may leave outer zones bare

District scatter count was reduced 1.0 to 0.4 to make room for road-edge layer.
Combined with the canvas expansion, outer districts (away from active roads)
may now appear under-vegetated. Mitigation: ring belt count 140 unchanged so
the city perimeter still reads green; outer district sparseness may even read
as "less-tested = barer" which matches the H.1 idea-draft semantics.
