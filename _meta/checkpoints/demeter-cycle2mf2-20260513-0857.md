### Cluster A: cache audit + fixes

Audited 3 cache layers. Findings + fixes:

1. **`DemeterRealService.list_findings_for_building(building_id)`** previously NO `repo_full_name` filter. Cross-repo collision risk when two repos share logical `building_id`. FIXED: added optional `repo_full_name` kwarg, propagated through `GET /api/findings/by-building/{id}?repo_full_name=owner/name`. Backwards compatible.

2. **`DiagramService._cache`** keyed by `repo_id` only. Silent collision when `register_repo()` remaps same `repo_id` to a different filesystem path. FIXED: cache key promoted to `(repo_id, str(repo_root.resolve()))`. `register_repo()` purges stale keys on path remap. `invalidate(repo_id)` walks tuple-first-slot.

3. **`SemanticCache`** previously single flat bucket. Cross-repo prompt poisoning risk above 0.85 cosine. FIXED: added optional `scope` kwarg, namespaced via `_buckets: dict[scope, (vectors, values)]`. Default `_default` scope preserves pre-existing behavior; callers can opt-in by passing `scope=repo_full_name`.

### Cluster B: LOC snapshot endpoint

`POST /api/activity/loc-snapshot` body `{timestamp, repo_root}` returns `{commit_sha, file_count, files: {path: loc}, cached, elapsed_ms, notes}`. Used by Boreas Time Machine scrubber.

- git rev-list resolves sha at-or-before timestamp on HEAD
- git ls-tree enumerates files at that commit
- per-file git cat-file size guard plus git show parallel via asyncio.gather plus Semaphore(8)
- 5 MB blob size cap guards binaries
- in-process cache 1-hour TTL keyed by `(resolved_repo_root_str, bucketed_iso_minute)`
- prehistoric timestamp returns empty plus `notes=["no_commit_before_timestamp"]`

Boreas concurrently extended request model with optional `repo_full_name` plus `nearby_commits[]` for tooltip card. Harmonized without conflict.

### Cluster C: per-file commits endpoint

`GET /api/buildings/{owner}/{repo}/{file_path:path}/commits` returns floor-ordered commit array. Floor 1 = oldest, floor N = newest. Persephone side panel plus Iris stacked-floor geometry consume.

- git log with follow, reverse, iso-strict date, custom pretty-format, numstat flags scoped to single file
- reverse flag guarantees chronological floor numbering
- follow flag survives rename history
- in-process cache 10-min TTL keyed by `(repo_root_str, file_path, branch)`
- `_resolve_repo_root()` walks explicit query, project working tree, datasets/, tests fixtures. 400 if unresolved (no silent fallback)
